# .github
PX4 Autopilot — открытая платформа автопилота для дронов и других беспилотных аппаратов. Поддерживает мультикоптеры, самолёты, VTOL и роверы, интеграцию с QGroundControl и MAVLink, автономные миссии, GPS-навигацию, телеметрию, датчики и широкую экосистему совместимых полётных контроллеров.
